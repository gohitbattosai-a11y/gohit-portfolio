# Gohit — Developer Portfolio

A responsive, high-performance portfolio website built to showcase custom Roblox Luau systems, combat mechanics, and data architecture.

## Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Smooth Scroll:** Lenis

## Features
- **Dynamic Theme Engine:** Real-time switching between 6 custom gradient presets via `gradients.js`.
- **Interactive Showcase:** Detailed project modals, video previews, and interactive cards.
- **Responsive Architecture:** Clean component structure optimized for all screen sizes.
